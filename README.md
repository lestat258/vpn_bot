# 🚀 VPN Telegram Bot

Telegram бот для продажи VPN-подписок с интеграцией 3X-UI.

## ✨ Возможности

- 🤖 Telegram бот для продажи VPN
- 🔗 Интеграция с 3X-UI панелью
- 💳 Приём платежей через ЮKassa
- 🖥️ Веб-админ панель
- 👥 Реферальная система
- 🔄 Автоматическое продление подписок
- 💾 Автоматические бэкапы

## Настройки размещения

Для бота, админки и webhook задавайте одинаковый `VPN4US_DATA_DIR`. Это абсолютный путь к каталогу с `data.db`, журналом бота и резервными копиями. По умолчанию используется каталог приложения. Шаблоны загружаются из каталога приложения.

- `VPN4US_ADMIN_ALLOWED_HOSTS` — разрешённые имена хостов через запятую.
- `VPN4US_ADMIN_CORS_ORIGINS` — разрешённые источники через запятую, со схемой и портом, если он нестандартный.

При запуске через systemd передайте эти значения через настройки окружения служб. Существующая установка в `/opt/vpn-bot` использует текущие пути и адреса по умолчанию.

### HTTPS для настроенного VPN4US

Создайте A-запись для отдельного поддомена VPN4US и направьте её на этот VPS. Укажите имя в `VPN4US_ADMIN_ALLOWED_HOSTS` для службы админки. Для автоматической настройки на Debian или Ubuntu службы админки и webhook должны отвечать на локальных портах 8000 и 8081, а входящие TCP-порты 80 и 443 должны быть доступны для Nginx.

```bash
sudo bash deploy/setup_https.sh bot.example.org admin@example.org
```

Скрипт добавляет виртуальный хост в Nginx, выпускает сертификат через Certbot и включает автопродление. Если 3x-ui или Xray уже занимает порт 80 или 443, скрипт остановится до изменения конфигурации. URL уведомлений, который напечатает скрипт, укажите в личном кабинете ЮKassa.

## Первоначальная установка админки

На чистом Debian или Ubuntu откройте скачанный Git-репозиторий и запустите:

```bash
sudo bash install.sh
```

В терминале укажите домен админки и email для сертификата. Установщик выведет ссылку, логин и временный пароль. При первом входе смените пароль.

- В разделе «Настройки» заполните токен Telegram, Telegram ID администратора и данные ЮKassa.
- В разделе «Серверы» добавьте URL и API-токен панели 3x-ui, затем задайте адрес подписок.
- В разделе «Налоги» настройте чеки. Цены и сроки укажите в разделе «Тарифы».

Эта версия установщика запускает админку. Активация бота и приём платежей после заполнения настроек — следующий этап разработки.
