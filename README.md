# 🚀 VPN Telegram Bot

Telegram бот для продажи VPN-подписок с интеграцией 3X-UI.

## ✨ Возможности

- 🤖 Telegram бот для продажи VPN
- 🔗 Интеграция с 3X-UI панелью
- 💳 Приём платежей через ЮKassa
- 🖥️ Веб-админ панель
- 👥 Реферальная система
- 🔄 Автоматическое продление подписок
- 💾 Автоматические бэкапы
